# Tools & Software

A collection of tools and software I have developed to support plant genomics, field phenotyping, and collaborative research.

---

## TraitTrack

**Platform:** iOS (iPhone & iPad)
**Developer:** Sumeet Mankar -- Schnable Lab, University of Nebraska-Lincoln
**License:** Free
**App Store:** [Download on the App Store](https://apps.apple.com/us/app/traittrack/id6798378635)

TraitTrack is a mobile field phenotyping app designed for collaborative, plot-level trait data collection in plant science research. Built for real field conditions, it supports multi-user projects with seamless data synchronization and conflict-safe merging.

### Key Features

- **Collaborative projects** -- One project owner, multiple collaborators working simultaneously in the field
- **Plot and trait-level data entry** -- Structured, consistent data capture across experiments
- **Metadata tracking** -- Automatically records observer, device, collection time, and sync status
- **Real-time sync** -- 30-second active-app sync cycle with automatic conflict resolution
- **Progress dashboard** -- Centralized view of collaborator progress and project-level summaries
- **Image workflow** -- Photo capture with full metadata synchronization
- **BrAPI integration** -- Import study/observation data and upload results via BrAPI
- **Cloud backend** -- Shared server storage via FastAPI and PostgreSQL

### Requirements

- iOS 17.0 or later
- iPhone or iPad
